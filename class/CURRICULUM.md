# AWS EKS: novice to expert — continuous class blueprint

Research cut: November 7, 2026, America/Los_Angeles (PST). Source-only phase: no presentation, narration, deployment or publication has been performed. Every address below is an illustrative teaching address, not an observed AWS deployment. Sources S01–S57 are indexed in REFERENCES.md and locally snapshotted.

## Audience, outcomes, prerequisites
Start with Linux processes, files, shell and TCP/IP; no Kubernetes experience assumed. Provide glossary before acronyms. By the end students can explain desired-state reconciliation, distinguish management from application access, build a private-worker Standard EKS cluster using AWS CLI v2, expose a constrained example service, trace packets both directions, diagnose layered failures, and plan safe scale, upgrade and recovery. Expert objectives mean reasoned operations and documented tradeoffs, not a claim that a single lab qualifies someone to operate production alone.

Prerequisites for hands-on: disposable AWS sandbox and permission boundary approved by its owner; AWS CLI v2, jq, kubectl compatible with cluster version, Helm 3 for LBC only, curl, Python 3, Bash; explicit region/account/admin IAM role/operator IPv4 /32; ability to assume that role; review costs and teardown first. No SSH key, root account, permanent access key or real customer data. Use SSO/short-lived credentials configured by the learner outside this bundle. Working labs are not prerequisites for watching the class.

## Pedagogy and continuous scene grammar
For EACH numbered lesson: definition and motivation → mechanism/progressive build → worked flow with forward AND return or acknowledgement → failure/repair → explained knowledge check → takeaway and next lesson. Concepts are real lecture compositions, not the same topology under different text. Labs immediately follow their concept/demo in one continuous class. Commands are revealed in readable chunks with expected output SHAPES marked illustrative; never voice-read long ARNs or JSON. No arbitrary runtime cap; final runtime is measured after narration generation, not estimated here. All stages must be included before describing the finished class as novice-to-expert.

Opening narration: “Welcome to the channel. Please subscribe.” Then outcomes and cost warning. Closing: “Thank you for watching. Please subscribe to get updates on future lessons when they are posted.” Natural male synthetic narration (approved baseline Kokoro am_michael) is a later build responsibility.
